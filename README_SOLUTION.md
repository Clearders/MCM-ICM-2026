# MCM Problem C Solution - Dancing with the Stars Analysis

This repository contains Python code to analyze the Dancing with the Stars (DWTS) competition data and answer the 4 questions posed in the 2026 MCM Problem C.

## Overview

The analysis addresses:
1. **Fan Vote Estimation** - Develop a model to estimate unknown fan votes based on elimination results
2. **Voting Method Comparison** - Compare rank-based vs percentage-based voting methods
3. **Characteristic Analysis** - Analyze impact of pro dancers and celebrity characteristics
4. **Improved System Proposal** - Propose a fairer/better voting system

## Files

### Analysis Scripts
- `question1_fan_vote_estimation.py` - Estimates fan votes using optimization
- `question2_voting_method_comparison.py` - Compares voting methods and analyzes controversial cases
- `question3_characteristics_analysis.py` - Analyzes pro dancer and celebrity characteristic impacts
- `question4_improved_voting_system.py` - Proposes improved voting systems
- `run_all_analyses.py` - Master script to run all analyses in sequence

### Data Files
- `2026_MCM_Problem_C.pdf` - Problem statement
- `2026_MCM_Problem_C_Data.csv` - Contest data (seasons 1-34)

### Output Files (generated by analysis)
- `question1_fan_vote_estimates.csv` - Estimated fan votes for all contestants/weeks
- `question1_consistency_metrics.csv` - Validation metrics for fan vote estimates
- `question2_method_comparison.csv` - Comparison of rank vs percentage methods
- `question2_judge_elimination_impact.csv` - Impact of judge elimination method
- `question3_pro_dancer_stats.csv` - Pro dancer performance statistics
- `question3_age_impact.csv` - Impact of celebrity age on performance
- `question3_industry_impact.csv` - Impact of celebrity industry on performance
- `question3_contestant_stats.csv` - Complete contestant statistics
- `question3_factor_weights.csv` - Factor weights from predictive models (judge scores and fan votes)
- `question4_proposed_system.csv` - Proposed voting system details

### Run Individual Analyses
```bash

# Question 2: Voting method comparison
python question2_voting_method_comparison.py

# Question 3: Characteristics analysis
python question3_characteristics_analysis.py

# Question 4: Improved voting system
python question4_improved_voting_system.py
```

**Note**: Questions 2-4 depend on outputs from Question 1, so run Question 1 first or use `run_all_analyses.py`.

## Methodology

### Question 1: Fan Vote Estimation
- Uses constrained optimization to estimate fan votes that lead to observed eliminations
- Implements both rank-based and percentage-based methods based on season
- Calculates certainty metrics for each estimate
- Validates consistency with actual elimination results

### Question 2: Voting Method Comparison
- Applies both rank and percentage methods to all seasons
- Identifies weeks where methods produce different outcomes
- Analyzes controversial cases (Jerry Rice, Billy Ray Cyrus, Bristol Palin, Bobby Bones)
- Simulates impact of judge elimination from bottom 2

### Question 3: Characteristics Analysis
- Analyzes pro dancer impact on judge scores and fan votes
- Examines celebrity age, industry, and other characteristics
- Builds predictive models using linear regression
- Compares how characteristics affect judges vs fans differently

### Question 4: Improved Voting System
- Proposes Dynamic Weighted Voting system
- Progressive shift from judge-heavy to fan-heavy weights
- Alternative systems: Cumulative scoring and Tiered elimination
- Simulates impact of proposed systems on historical data

## Key Findings

The analysis reveals:
- Estimated fan vote patterns across 34 seasons
- Differences in outcomes between rank and percentage methods
- Impact of pro dancers on contestant success
- Celebrity characteristics that influence performance
- Recommended voting system balancing fairness and excitement
